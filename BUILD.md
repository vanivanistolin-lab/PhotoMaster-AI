# Автоматическая сборка Windows

Для использования программы сборка не требуется: готовый PhotoMaster.exe находится в портативном ZIP.

Исходники содержат `.github/workflows/windows.yml`. После размещения содержимого
этой папки в собственном репозитории GitHub откройте Actions → Build PhotoMaster Windows → Run workflow.
После успешного завершения скачайте артефакт PhotoMaster-Windows-x64.
Все инструменты устанавливаются на временной машине GitHub. На компьютере пользователя
ничего устанавливать и запускать в CMD не нужно. Использование GitHub Actions зависит от
доступности сервиса и лимитов аккаунта. Рабочие фотографии для сборки не нужны.

Workflow компилирует EXE со статическим C++ runtime, встраивает иконку и манифест,
запускает 43 проверку обработки под Windows и упаковывает программу как артефакт.
Workflow успешно выполнен на Windows в GitHub Actions, включая все 43 тест:
https://github.com/vanivanistolin-lab/PhotoMaster-AI/actions/runs/42255767846

Эта поставка собрана в Linux через MinGW-w64 GCC 14; запуск и тесты выполнены через Wine 10.
`tests.cpp` создаёт синтетические изображения и проверяет реальные функции редактора.
Тестовый EXE предназначен только для сборки и не входит в пользовательскую программу.
